# Physiological Signal Analysis for Emotion Detection

A data-focused project centered on exploratory analysis and feature preprocessing of physiological sensor signals for downstream emotion classification.

## What this project does
- Performs exploratory data analysis on raw physiological sensor data
- Applies calibration and preprocessing to clean noisy sensor readings
- Extracts structured features suitable for supervised learning
- Establishes a reproducible data pipeline for future model training

## System overview
Raw physiological sensor readings are cleaned, normalized, and transformed into structured features. The focus of this project is on data quality and signal preparation rather than model training.

## Tech stack
- Python
- NumPy
- Pandas

## Current status
This repository covers data exploration and feature engineering only. Model training and hardware integration are out of scope at this stage.
